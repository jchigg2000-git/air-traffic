01 · The divergence

Sixteen vendors.
Sixteen control dialects.

There is no shared vocabulary for governing AI. One vendor caps spend in cents on a project; the next has no hard cap at all and tells you to build a proxy. Each returns its own error envelope, names its own primitives, and draws its own line between “you can set this” and “you can only watch it.” Air‑Traffic serves a byte‑identical synthetic replica of every one.

Multiply that by sixteen and the dashboard problem is obvious: you cannot compare what you cannot put in one shape. So Air‑Traffic builds a spine — a single normalization path every vendor feeds into.

04 · The honesty axis

A control is only as true as its disposition.

Every capability carries exactly one of five dispositions — the difference between “we set this through the vendor’s API” and “we can only watch it drift.” Scrub one capability across all five and watch the claim Air‑Traffic is willing to make change with it.

05 · The catch · enforcement tiers

When env_managed isn’t enough,
the badge is denied.

An env_managed capability carries a second truth: its enforcement tier. server_side is non‑bypassable. mdm_locked only holds on managed devices. seed_only just writes a default the user can override — so Air‑Traffic refuses to stamp it “enforced.” Pick a real capability and watch the resolver decide.

06 · What the spine carries

Three control planes, one bus.

The normalized signal is dimensioned by plane. Three planes carry intent — developer‑workflow, data‑policy, budget — and all three drain into the fourth, observability: the ops‑observation‑batch/v1 stream, drift, and SIEM export.

08 · What this does not claim

The honesty is the product.

A control plane that overstates its reach is worse than none. Air‑Traffic is built to under‑claim on purpose — here is exactly where its truth runs out.

Honest caveats

  • Phase 1 is synthetic. The surfaces here are a byte‑identical synthetic replica of each vendor’s admin API — Go stdlib, zero dependencies. No live vendor traffic touches this page.
  • It is not an inline proxy. Air‑Traffic reads and writes admin/control surfaces. The only thing that can ever sit on the request path is an optional gateway — which is why proxy_enforced capabilities read as needing that gateway, not as “enforced”. (Written for Phase 1. The inference gateway shipped in Phase 3 on 2026‑07‑02 and now runs as a container in the default stack; see README.md. The UI label is “Proxy (opt)” — web/src/lib/dispositions.ts.)
  • Token volumes are labeled synthetic. The slider value in §03 is illustrative; the green/amber/red thresholds it crosses are the catalog’s real ones.
  • There is a sixth verdict. Beyond the five dispositions a capability can carry, coverage reconciliation reports unsupported for a control a vendor simply does not have — so the UI never invents one.
  • seed_only is humility in code. A managed default a user can override is drift‑detect only. The UI is forbidden from rendering it as “enforced” — the rule you watched fire in §05.
