# Air-Traffic Logo Pack — Option 4

This pack is based on option 4: the holding-pattern mark.

## Concept

Air traffic control does not just watch planes. It separates traffic, queues aircraft safely, redirects movement, and authorizes entry into controlled airspace.

This mark uses a simplified holding-pattern path:
- the loop implies controlled queueing, routing, and release
- the arrow implies authorized forward movement
- the start node implies a tracked AI request, agent, or workflow entering the control plane
- the shape remains flat, invertible, and usable at small sizes

## Recommended usage

Use `air-traffic-icon-dark.svg` for app icons and dark UI surfaces.
Use `air-traffic-icon-light.svg` for documents and light UI surfaces.
Use the transparent mark only when placing the mark on a controlled background.
Use the mono variants when color is unavailable or when embedding in dense enterprise UI.
